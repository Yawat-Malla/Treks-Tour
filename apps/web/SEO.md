# SEO launch checklist — Upper Path Treks

Domain: `https://upperpathtreks.com`

This is operator work after the site is live on HTTPS. Rankings will not move until Google can crawl, and “#1 for treks” is not a KPI. Named routes and “best treks in Nepal” are.

## Week 0 — go live

1. Set `NEXT_PUBLIC_SITE_URL=https://upperpathtreks.com` on the host.
2. Confirm `info@upperpathtreks.com` (or the real inbox) in Studio → Name, logo & phone, and in SMTP/`COMPANY_EMAIL`.
3. Open `/robots.txt` and `/sitemap.xml`. Every public locale URL should be listed. `/book` and the studio path must be disallowed.
4. Google Search Console: add the domain property, paste the verification code into Studio → Google Search Console code, submit `https://upperpathtreks.com/sitemap.xml`.
5. Request indexing on `/`, `/treks`, `/destinations/annapurna`, `/blog/best-treks-in-nepal`, and the top commercial treks (Poon Hill, Mardi Himal, ABC, Circuit, EBC, Mustang).
6. Google Analytics 4 on the live domain.

## Google Business Profile (Pokhara)

- Name exactly **Upper Path Treks And Tours** (do not collide with Higher Path Treks).
- Category: Tour operator / Hiking service.
- Address: Lakeside, Pokhara-6, Kaski, Nepal.
- Photos of the office, guides, and trail (original, not Unsplash).
- Weekly posts in season; answer Q&A.
- Paste the GBP URL into Studio → Google Business Profile URL so schema `sameAs` matches.

## Reviews and citations

- Ask walkers for Google and TripAdvisor reviews after they descend.
- List on TAAN / NTB / Visit Nepal directories with the same NAP (name, address, phone, email).
- Fill Facebook, Instagram, TripAdvisor URLs in Studio once the profiles exist.

## Content cadence

- Update `/blog/best-treks-in-nepal` in place every September (year, prices, permit notes). Do not create a new slug.
- Refresh trip prices and permit copy when immigration notices change.
- Replace stock Unsplash heroes with original trail photos as they land.

## 90 / 180 / 365 days

- 90: indexed URL count ≈ sitemap; branded + 5 named-trek impressions.
- 180: page-one long-tails such as “mardi himal trek from pokhara”; pillar inside the top 20 for “best treks in Nepal”.
- 365: page one for several Pokhara-start named routes if reviews and unique photos keep up.
